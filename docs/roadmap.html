Roadmap

The next milestone is a field test on both Pi models. Each result will identify the SD image, flight controller and Betaflight version so another pilot can repeat it.

Collect a flight on each Pi

Flash the same image to spare cards for a Zero W and a Zero 2 W. With erase and cleanup off, copy a real recording twice, unplug the controller and download the file over the hotspot. Check its checksum and open it in Betaflight’s Blackbox Viewer.

Interrupt a separate copy and compare the dashboard and activity LED with the saved result. Check that the hotspot stays available after unplugging and that optional idle shutdown leaves an active copy alone.

Recover an offline update

Install a signed update on a spare card, reboot and check the version, Wi-Fi settings and saved recordings. Then interrupt an installation and check that the Pi can recover the previous version. Check the documented upgrade path for each supported older Go image in the upgrade table.

Hand the kit to another pilot

Give an independent pilot the setup guide and a spare card. Can they find their latest flight on a phone, open the recording and apply an offline update without coaching? Record where they get stuck.

Completed runs belong in the test record. The release checklist covers the remaining maintainer checks.

What would change controller support?

Betaflight on internal SPI flash is the focus. Before adding iNav, the copier would need to handle its flash read format and produce a recording that opens in the Viewer on real hardware. There is no scheduled iNav release.
